# තිස්සපෑල විද්‍යාකීර්ති මහා පිරිවෙන — වෙබ් අඩවිය

සිංහල, English, தமிழ் භාෂා තුනෙන් සකස් කළ වෙබ් අඩවිය. ඉතිහාසය, අධ්‍යාපනය, නායකත්වය, ජයග්‍රහණ, ඡායාරූප, අනුබද්ධ ආගමික ස්ථාන, වීඩියෝ, QR මඟපෙන්වීම සහ Google Maps පිහිටීම ඇතුළත් වේ.

## GitHub Pages වෙත දමන හැටි

1. ZIP ගොනුව **Extract** කරන්න.
2. GitHub වෙත පිවිස `vidyakeerthi-pirivena` repository එක විවෘත කරන්න. Repository එක නොමැති නම් ඒ නමින් **Public** repository එකක් හදන්න.
3. **Add file → Upload files** යන්න. Extract කරපු folder එක ඇතුළේ තිබෙන **`index.html`, `app.js`, `styles.css`, `translations-ta.js`, `assets/` folder** සහ අවශ්‍ය අනෙක් ගොනු repository එකේ මුල් පිටුවට upload කරන්න. `dist` කියන අමතර folder එකක් ඇතුළට දමන්න එපා.
4. **Commit changes** ඔබන්න.
5. **Settings → Pages → Build and deployment** යටතේ **Deploy from a branch**, Branch **main**, Folder **/(root)** තෝරා **Save** කරන්න.
6. සයිට් එක පළවීමට මිනිත්තු කිහිපයක් ගත විය හැක. **Settings → Pages** මත link එක බලන්න.

පසුව අවශ්‍ය නම් ඔබ මිලදී ගන්නා domain එකම මේ GitHub Pages site එකට යොමු කළ හැක. Domain එක ලබාගත් පසු DNS සහ Custom domain settings සකස් කරමු.

## ගොනු ගැන

- `index.html`: සම්පූර්ණ පිටුවේ කොටස් සහ අන්තර්ගතය.
- `styles.css`: ලස්සන නිර්මාණය, animations, desktop/mobile layouts.
- `app.js`: භාෂා මාරු කිරීම, timeline, ඡායාරූප විශාල කිරීම සහ menu.
- `translations-ta.js`: දෙමළ පරිවර්තන.
- `assets/`: පිරිවෙනේ මුල් ඡායාරූප, සම්මාන පිටු, අනුබද්ධ ස්ථාන වීඩියෝව, font files, සහ ඉතිහාස PDF එක.

වීඩියෝව 3.3 MB පමණ වන ලෙස දත්ත ඉතිරිකරමින් සකස් කර ඇත. මෙය Play කරන තුරු browser එක video ගොනුව download නොකිරීමට සකස් කර ඇත.
